# Skrolcartt - E-Commerce App

An Android e-commerce shopping application built with Kotlin, featuring product browsing, cart management, and a smooth checkout experience.

## Features

- Product catalog with categories
- Shopping cart management
- User authentication
- Order placement
- Product search and filters
- Material Design UI

## Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **Backend:** Firebase
- **UI:** Material Design
- **Image Loading:** Glide

## Getting Started

1. Clone the repository
```
git clone https://github.com/bhartendukodes/Skrolcartt.git
```
2. Open in Android Studio
3. Add your `google-services.json`
4. Build and run
